# Security policy

Brandle stores game progress in the local browser and has no account backend in the current standalone source. Please protect any personal data or browser storage included in a report.

Please do not open a public issue for suspected vulnerabilities, authentication bypasses, exposed credentials or private-data exposure. Report them privately to **devon@anevum.com**. Include the affected commit or component, reproduction steps and potential impact, with personal data and credentials removed.

Avoid destructive tests, denial of service, social engineering, accessing other people's data or changing production state. Stop and report if you encounter private data or credentials. There is no announced public bug bounty.
